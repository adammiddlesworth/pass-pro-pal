# PassPal Prep

I'd like to build an app for an idea I have called PassPal.

This is an app that would help people pass their real estate licensing exam or their life and health insurance exam. 

I want to have practice exams for the real estate licensing course and practice exams for the life and health insurance exams. 

I am marketing this with practice exams on youtube. Each exam should be able to point to the app where the exam will live. 

There is a similar app already called Birdsy.ai that essentially does the same thing.
